# binaryloader-extensions

iOS 개발에 유용한 Swift 익스텐션 모음이며 CocoaPods pod으로 배포한다.

## Extensions

- `Collection+Safe` - 옵셔널을 반환하는 안전한 서브스크립트 접근
- `NSMutableAttributedString+Helper` - 텍스트 속성을 위한 fluent API
- `NSObject+Bundle` - 손쉬운 번들 접근
- `NSObject+ClassName` - 클래스 이름을 문자열로 가져오기
- `String+URL` - 문자열을 URL로 변환
- `StringProtocol+Range` - 문자열 범위 유틸리티
- `UIFont+Safe` - 폴백을 포함한 안전한 폰트 초기화
- `UIView+Helper` - NIB에서 로드하고 타입으로 서브뷰 찾기

## Installation

```ruby
source 'https://github.com/binaryloader/cocoapods-specs.git'

pod 'BinaryLoaderExtensions'
```
