# binaryloader-extensions

iOS開発に役立つSwift拡張機能のコレクションで、CocoaPods podとして配布しています。

## Extensions

- `Collection+Safe`：オプショナルを返す安全なサブスクリプトアクセス
- `NSMutableAttributedString+Helper`：テキスト属性のためのfluent API
- `NSObject+Bundle`：簡単なバンドルアクセス
- `NSObject+ClassName`：クラス名を文字列として取得
- `String+URL`：文字列をURLに変換
- `StringProtocol+Range`：文字列範囲のユーティリティ
- `UIFont+Safe`：フォールバック付きの安全なフォント初期化
- `UIView+Helper`：NIBからの読み込みと型によるサブビュー検索

## Installation

```ruby
source 'https://github.com/binaryloader/cocoapods-specs.git'

pod 'BinaryLoaderExtensions'
```
